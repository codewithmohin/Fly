# Mohin Cinematic Portfolio

A single-page cinematic developer portfolio built with:

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP 3
- Responsive CSS
- Custom cursor
- Section transitions
- Keyboard / wheel / touch navigation
- Mobile menu
- Preloader
- Progress bar
- Legal modal

## Run

Open `index.html` in a browser.

For best local development, use VS Code + Live Server.

## Before publishing

1. Replace `your@email.com` with your real email.
2. Replace GitHub and LinkedIn links.
3. Replace placeholder project/hackathon information with your real work.
4. Add your own images/videos in `assets/`.
5. Replace the placeholder privacy/imprint text with your actual legal content.
6. If you add videos, optimize/compress them before deployment.

## Main architecture

HTML = structure/content  
CSS = visual system/responsive design  
JavaScript = navigation/interaction/state  
GSAP = cinematic transitions and motion
