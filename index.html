About HTML

HTML stands for HyperText Markup Language. It is used to create and structure web pages. HTML uses different tags to display content like text, images, links, and forms.

About CSS

CSS stands for Cascading Style Sheets. It is used to style HTML elements. With CSS we can change colors, fonts, spacing, and layouts of web pages.

About JavaScript

JavaScript is a programming language used to make websites interactive. It allows features like animations, form validation, and dynamic content.
